# Inspiracje

## Słowa, skojarzenia, pomysły

Organizacja, planowanie, student, nauka, struktura, zadania, kalendarz, przejrzystość.

## Lista elementów projektu

- Lista zadań
- Kalendarz tygodniowy
- Proste statystyki
- Powiadomienia o zbliżających się terminach
- Kategoryzacja zadań

## Wstępne dane wejściowe

- Kategorie: zajęcia, projekty, egzaminy, inne
- Funkcje: dodawanie zadań, edycja, usuwanie, oznaczanie jako wykonane
- Widoki: dzienny, tygodniowy, miesięczny

## Źródła pomysłu

- Własna potrzeba uporządkowania nauki
- Rozmowy ze znajomymi studentami
- Obserwacja problemów z organizacją czasu na studiach
